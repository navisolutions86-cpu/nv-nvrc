Cấu Hình Kết Nối Cơ Sở Dữ Liệu Supabase Cloud

Tự động kết nối & đồng bộ mỗi 5 giây giữa NAVI và NVRC trên mọi thiết bị

Chưa kết nối Đồng bộ gần nhất: Chưa đồng bộ

Lấy tại Supabase → Project Settings → Data API → Project URL

Sử dụng khóa publishable / anon public (không dùng service_role key)

Chạy đoạn SQL này trong Supabase → SQL Editor trước khi kết nối: 
CREATE TABLE IF NOT EXISTS public.nv_nvrc_app_state (
    id TEXT PRIMARY KEY,
    payload JSONB NOT NULL,
    updated_by TEXT,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

GRANT USAGE ON SCHEMA public TO anon, authenticated;
GRANT SELECT, INSERT, UPDATE, DELETE ON TABLE public.nv_nvrc_app_state TO anon, authenticated;

ALTER TABLE public.nv_nvrc_app_state ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Allow read app state" ON public.nv_nvrc_app_state;
CREATE POLICY "Allow read app state" ON public.nv_nvrc_app_state FOR SELECT TO anon, authenticated USING (true);

DROP POLICY IF EXISTS "Allow insert app state" ON public.nv_nvrc_app_state;
CREATE POLICY "Allow insert app state" ON public.nv_nvrc_app_state FOR INSERT TO anon, authenticated WITH CHECK (true);

DROP POLICY IF EXISTS "Allow update app state" ON public.nv_nvrc_app_state;
CREATE POLICY "Allow update app state" ON public.nv_nvrc_app_state FOR UPDATE TO anon, authenticated USING (true) WITH CHECK (true);

NOTIFY pgrst, 'reload schema';
